# T001 [점검] 사번 범위 조회

> 시스템 점검용 문제입니다. 스터디 진도와는 관계없어요.

사번(`empno`)이 1~1000인 사원의 이름을 조회하세요. 결과 순서는 채점하지 않아요.

- 사용 테이블: `study.emp` (10만 건, `emp_pk`: empno, `emp_dept_ix`: deptno)
- 비효율 쿼리는 테이블 전체를 읽어요. 필요한 1%만 읽도록 바꿔 보세요.

## 스키마

```sql
-- 테스트 데이터셋: 사원 10만 건. empno 순서로 적재되어 empno 범위 조회는 클러스터링이 좋다.
CREATE TABLE emp (
  empno   NUMBER       NOT NULL,
  deptno  NUMBER       NOT NULL,
  ename   VARCHAR2(20) NOT NULL,
  sal     NUMBER(7, 2),
  CONSTRAINT emp_pk PRIMARY KEY (empno)
)
/
CREATE INDEX emp_dept_ix ON emp (deptno)
/
```

목표: Buffers ≤ 20
